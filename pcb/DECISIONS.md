Instead of the original idea of the device being able to detect notes and light them up on the fretboard, I decided to use the phones microphone and use the phone as a processor. so all the transcribing happens on the phone and the device itself only says what notes to play. This is so that the Firmware and pcb is more easy to make and the cost lowers. it's easier to debug a problem on the phone rather than a analog audio system

30 OCT 2026 3:47 PM: After thinking for a while i feel like this project is too complicated. i'm completely removing the idea of connecting it to a phone so that no wireless code is required.
